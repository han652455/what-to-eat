# 今天吃什么

一个**手机优先、纯前端、零联网**的家庭饮食小助手：随手记录菜谱与早餐食材，一键随机生成正餐/早餐，自动留存用餐历史（日历可回看），数据全部存在你自己的浏览器里。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 应用本体（HTML/CSS/JS 全内联，单文件，双击或浏览器打开即用） |
| `manifest.webmanifest` | PWA 清单，用于「添加到主屏幕」后全屏运行 |
| `icon.svg` | 应用图标 |
| `sw.js` | Service Worker，缓存应用外壳实现离线可用 |
| `PRD.md` | 产品需求文档（功能与验收依据） |
| `开发计划.md` | 开发计划与里程碑 |
| `tests/run.js` | 自动化验收测试（jsdom） |

> `tests/` 与 `README.md` 等仅为开发与文档资料，运行应用只需 `index.html`（及可选的 `manifest.webmanifest` / `icon.svg` / `sw.js`）。

## 怎么用

### 方式一：直接打开（最简单）
把 `index.html` 发到手机，用浏览器打开即可。所有数据存在该浏览器本地。

### 方式二：添加到主屏幕（像 App 一样全屏）
需要通过 **http(s)** 访问（直接 `file://` 打开时不会注册 Service Worker，属于正常）：
1. 用任意静态服务器托管本目录，例如：
   ```bash
   # Python
   python3 -m http.server 8000
   # 或 Node
   npx serve .
   ```
2. 手机浏览器访问 `http://<电脑IP>:8000/index.html`。
3. iOS Safari：点「分享」→「添加到主屏幕」。Android Chrome：点「菜单」→「安装应用 / 添加到主屏幕」。
4. 之后从主屏幕图标打开即为全屏 App，且可离线使用。

## 功能速览

- **菜谱（Tab ①）**：批量粘贴导入、单条新增、自动分 6 类（荤菜/素菜/半荤半素/甜汤/咸汤/大锅菜）、行内改分类、单条删除、勾选批量删除、临时排除（仅影响本轮）。
- **生成（Tab ②）**：进入后分「正餐」「早餐」两个板块。
  - 正餐：普通随机（菜品数+汤数）、大锅菜模式（系统随机抽一口）、冰箱临时抽取（不落库）。
  - 早餐：独立食材库、强制带上清单（可增删改）、外出概率（0–30%，命中整餐标记外出）、按样数生成。
- **历史（Tab ③）**：默认日历视图（有记录的日子带点，点那天看吃了什么），可切列表视图，按全部/正餐/早餐筛选；每条可编辑、可删除。
- **设置（右上角齿轮）**：6 套粉彩主题、明暗（浅色/深色/跟随系统）、背景图（按主题单独上传，仅存本机）、备份导出/导入、清空数据。

## 数据备份与迁移

- 数据存在当前浏览器的 `localStorage`，**清浏览器数据会丢，换设备不会自动同步**。
- **备份**：设置 → 生成备份文本 → 复制，存到备忘录。备份包含：正餐菜谱 + 早餐食材 + 全部历史 + 当前设置。
- **恢复**：设置 → 粘贴备份文本 → 恢复数据（会覆盖当前全部数据，操作前有确认）。
- **背景图不进备份**：背景图单独存在本机，体积较大，不适合塞进备忘录；换设备后需重新上传。

## 主题与外观

- 内置 6 套粉彩主题（红白复古 / 元气草莓 / 蓝格清晨 / 深海气泡 / 奶油幸运 / 深蓝星夜），各含亮/暗两档。
- 「跟随系统」会随手机深浅色设置自动切换。
- 背景图由你自己上传，应用只作为个人壁纸显示（参考图里的版权角色不会内置）。
